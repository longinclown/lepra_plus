Lepra+ 1.1

Chrome MV3 extension for Leprosorium.

Functions:
1. Раскрашивать рейтинг комментариев
2. Нумерация пользователей
3. Половая принадлежность (мужчина/женщина)
4. Заголовок поста во вкладке браузера
5. Предварительный просмотр поста/комментария

Popup:
- карма пользователя;
- непрочитанные посты/комментарии в «Мои вещи»;
- непрочитанные посты/комментарии в «Инбокс».

В версии 1.1 старый /api/lepropanel больше не используется.
Данные берутся из актуальных запросов, которые сам сайт выполняет:
- GET /api/users/<login>/info/?page=1
- POST /ajax/interest/moar/
- POST /ajax/inbox/moar/

Запросы выполняются из контекста открытой страницы leprosorium.ru, поэтому используются
текущая авторизация и CSRF-токен сайта. Расширение не сохраняет cookies, SID или CSRF-токен.

Для popup должен быть открыт хотя бы один tab с leprosorium.ru. После установки откройте
leprosorium.ru, обновите страницу (Ctrl+R), затем нажмите иконку Lepra+.

Если popup не может получить данные, сообщение содержит конкретную причину.
