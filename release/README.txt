Lepra+ 1.2
Дополнительные опции кастомизации для сайта Лепрозорий (leprosorium.ru)
Chrome MV3 extension for Leprosorium.

=== ФУНКЦИИ ===

1. Раскрашивание рейтинга комментариев.
2. Определение половой принадлежности пользователей (синим цветом выделяются "мужчины", красным - "женщины").
3. Нумерация пользователей - %username% [xxxx].
4. Отображение текста шапки поста во вкладке браузера.
5. Предпросмотр постов и комментариев перед добавлением.
6. Статистика аккаунта в pop-up (Карма, Мои вещи, Инбокс).
7. Индикация на значке расширения (отслеживание Кармы, Рейтинга комментариев, а также новых постов и комментариев в разделах «Мои вещи» и «Инбокс»).
8. Автоматическое обновление данных после авторизации на сайте.

=== УСТАНОВКА В CHROME ===

Если конкретная сборка Chrome разрешает локальную установку CRX:
1. Откройте в адресной строке chrome://extensions.
2. Переместите мышкой файл Lepra_plus_1.2_chrome_opera.crx в окно браузера со списком расширений.
3. Если Chrome покажет запрос, нажмите «Установить расширение».

Если Chrome блокирует локальный CRX, используйте ZIP:
1. Распакуйте архив в постоянную папку.
2. Откройте chrome://extensions и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку, в которой находится manifest.json.

=== УСТАНОВКА В OPERA ===

Если конкретная сборка Opera разрешает локальную установку CRX:
1. Откройте opera://extensions.
2. При необходимости включите «Режим разработчика».
3. Переместите файл Lepra_plus_1.2_chrome_opera.crx мышкой в окно со списком расширений.
4. Нажмите «Установить» и подтвердите «Да, установить».

Если Opera не принимает CRX:
1. Распакуйте ZIP в постоянную папку.
2. Откройте opera://extensions.
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное».
4. Выберите папку расширения с файлом manifest.json.

==============================

=== ПЕРВОЕ ИСПОЛЬЗОВАНИЕ ===

1. После установки откройте leprosorium.ru и войдите в аккаунт.
2. Обновите вкладку сайта (Ctrl+R), чтобы content script расширения подключился к странице.
3. Нажмите иконку Lepra+, popup запросит статистику.
4. При повторном открытии popup последние сохранённые данные отображаются сразу; обновление выполняется параллельно в фоне. При поступлении свежих данных значения в открытом popup обновляются автоматически.
5. Если кэш ещё пуст и расширение не может получить данные, popup показывает причину (например, "сайт не открыт", "вкладка не обновлена" или "запрос завершился ошибкой").

=== ОПИСАНИЕ И ИСТОРИЯ ГЛОБАЛЬНЫХ ИЗМЕНЕНИЙ ===

1. За основу взято расширение https://github.com/Rpsl/leprosorium/ и переписано под Manifest V3.
2. Неактуальные на текущий момент опции удалены. Старый API из lepropanel больше не используется.
3. Сохранены и адаптированы основные функции расширения: раскраска рейтинга комментариев, нумерация пользователей, обозначение пола, заголовок поста во вкладке браузера и предварительный просмотр постов/комментариев, popup со статистикой аккаунта: карма, непрочитанные посты и комментарии в «Мои вещи» и «Инбокс».
4. Реализована новая архитектура получения статистики для popup: service worker обращается к content script открытой вкладки Leprosorium, а запросы к API выполняются из контекста самой страницы.
5. Данные берутся из актуальных запросов сайта:
   - GET /api/users/<login>/info/?page=1
   - POST /ajax/interest/moar/
   - POST /ajax/inbox/moar/
6. Логин текущего пользователя определяется из активной страницы Leprosorium. Запросы выполняются с same-origin credentials и CSRF-токеном, полученным из DOM страницы. Используется действующая авторизация сайта. Расширение не сохраняет cookies, SID или CSRF-токен в собственном хранилище; отдельное разрешение cookies не требуется.
7. Реализовано кэширование статистики в chrome.storage.local. При открытии popup последние успешно полученные данные выводятся сразу, без ожидания сетевых запросов; одновременно запускается фоновое обновление. После получения свежих данных открытый popup обновляет значения автоматически. Если запрос завершается ошибкой, сохраняются последние успешные данные и показывается ненавязчивое сообщение.
8. Добавлено фоновое обновление по расписанию (раз в минуту), при запуске браузера и при изменениях вкладок Leprosorium. Получение свежих данных возможно, пока в браузере доступна открытая вкладка сайта с подключённым content script.
9. Добавлено обновление значка расширения: в настройках можно выбрать отображаемое значение (карма, рейтинг комментариев, «Мои вещи» или «Инбокс»).
10. Добавлены диагностические сообщения: если данные получить не удалось, popup показывает конкретную причину и рекомендуемое действие.
