Lepra+ 1.2.1
Дополнительные опции кастомизации для сайта Лепрозорий (leprosorium.ru)
Chrome MV3 extension for Leprosorium.

=== ФУНКЦИИ ===

1. Раскрашивание рейтинга комментариев.
2. Определение половой принадлежности пользователей (синим цветом выделяются "мужчины", красным - "женщины").
3. Нумерация пользователей - %username% [xxxx].
4. Отображение текста шапки поста во вкладке браузера.
5. Предпросмотр постов и комментариев перед добавлением.
6. Статистика аккаунта в pop-up (Карма, Мои вещи, Инбокс).
7. Индикация на значке расширения (отслеживание Кармы, Рейтинга комментариев, а также новых постов и комментариев в разделах «Мои вещи» и «Инбокс»).
8. Автоматическое обновление данных после авторизации на сайте.

=== УСТАНОВКА В CHROME/OPERA ===

Если конкретная сборка Chrome/Opera разрешает локальную установку CRX:
1. Откройте в адресной строке chrome://extensions (для Chrome) или opera://extensions (для Opera).
2. При необходимости включите «Режим разработчика».
3. Переместите мышкой файл CRX в окно браузера со списком расширений.
4. В Chrome нажмите «Установить расширение». В Opera нажмите «Установить» и подтвердите «Да, установить».

Если Chrome/Opera блокирует локальный CRX, используйте ZIP:
1. Распакуйте ZIP в постоянную папку.
2. Откройте chrome://extensions (для Chrome) или opera://extensions (для Opera) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку, в которой находится manifest.json

=== ПЕРВОЕ ИСПОЛЬЗОВАНИЕ ===

1. Убедитесь, что в браузере выполнен вход на leprosorium.ru. Для фонового получения статистики достаточно действующей сессии — открытая вкладка сайта не обязательна.
2. Чтобы функции кастомизации применились к странице, откройте leprosorium.ru и обновите вкладку (Ctrl+R), чтобы content script расширения подключился к странице.
3. Нажмите иконку Lepra+ — popup сразу покажет кеш (если он уже есть), а обновление запустится независимо от popup и открытых вкладок сайта.
4. При повторном открытии popup последние сохранённые данные отображаются сразу; обновление выполняется параллельно в фоне. При поступлении свежих данных значения в открытом popup обновляются автоматически.
5. Если кэш ещё пуст и расширение не может получить данные, popup показывает причину (например, "сайт не открыт", "вкладка не обновлена" или "запрос завершился ошибкой").

=== ОПИСАНИЕ И ИСТОРИЯ ГЛОБАЛЬНЫХ ИЗМЕНЕНИЙ ===

1. За основу взято расширение https://github.com/Rpsl/leprosorium/.
2. Неактуальные на текущий момент опции удалены. Старый API из lepropanel больше не используется.
3. Сохранены и адаптированы основные функции расширения: раскраска рейтинга комментариев, нумерация пользователей, обозначение пола, заголовок поста во вкладке браузера и предварительный просмотр постов/комментариев.
4. Реализовано получение статистики двумя способами: основной — прямые авторизованные запросы из фонового service worker, резервный — через content script открытой вкладки Leprosorium. Благодаря основному способу данные обновляются, даже когда все вкладки сайта закрыты.
5. Данные берутся из актуальных запросов сайта:
   - GET /api/users/<login>/info/?page=1
   - POST /ajax/interest/moar/
   - POST /ajax/inbox/moar/
6. Для фоновых запросов расширение временно читает cookies текущей сессии uid и sid через разрешение cookies, получает CSRF-токен из авторизованной страницы /my/ и выполняет запросы с текущей авторизацией. Cookies, SID и CSRF-токен не записываются в хранилище расширения и не передаются сторонним сервисам. Если прямой запрос недоступен, используется резервный способ через открытую вкладку сайта.
7. Добавлен popup со статистикой аккаунта: карма, непрочитанные посты и комментарии в «Мои вещи» и «Инбокс».
8. Реализовано кэширование статистики в chrome.storage.local. При открытии popup последние успешно полученные данные выводятся сразу, без ожидания сетевых запросов; одновременно запускается фоновое обновление. После получения свежих данных открытый popup обновляет значения автоматически. Если запрос завершается ошибкой, сохраняются последние успешные данные и показывается ненавязчивое сообщение.
9. Добавлено фоновое обновление по расписанию (раз в минуту), при запуске браузера и при изменениях вкладок Leprosorium. Благодаря прямым запросам из service worker обновление продолжает работать и при отсутствии открытых вкладок сайта, если сессия Leprosorium остаётся действующей.
10. Добавлено обновление значка расширения: в настройках можно выбрать отображаемое значение (карма, рейтинг комментариев, «Мои вещи» или «Инбокс»).
11. Добавлены диагностические сообщения: если данные получить не удалось, popup показывает конкретную причину и рекомендуемое действие.
